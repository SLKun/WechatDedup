# 微信附件去重工具

通过 NTFS 硬链接（hardlink）识别并合并微信 PC 端 `FileStorage\File` 目录下内容相同的附件，释放重复占用的磁盘空间，同时保持微信访问路径和文件名不变。

## 前情提要

Windows 微信 PC 端会长期保留内容完全相同的文件类附件（如多次转发的同一份 PDF、文档、压缩包），每一份都独立占用磁盘空间。WechatDedup 通过内容摘要（BLAKE3）识别重复附件，并利用 NTFS 硬链接让多份同名附件共享同一份物理数据，从而在不影响微信正常使用的前提下释放磁盘空间。

## 核心特性

- **按需扫描**：启动后展示全部账号清单，进入某个账号才触发扫描，不必等待全量扫描
- **内容摘要复用**：文件大小和修改时间未变时跳过重复计算，重新扫描只重新读取变化的文件
- **BLAKE3 内容摘要**：相比传统哈希算法，大文件摘要计算提速约 10 倍
- **三种操作**：纳管（确认/合并硬链接关系）、清理（释放重复占用）、回溯（恢复为独立文件）
- **追加式操作历史**：所有经确认的操作永久记录于 SQLite，支持按文件/组/账号级回溯
- **安全守卫**：每次操作前检测微信进程，运行中微信会阻止文件替换
- **全键盘 TUI**：基于 [Textual](https://github.com/Textualize/textual) 框架的全屏终端界面，高效浏览和操作

## 安装

需要 Windows + NTFS 文件系统、Python 3.10+ 和 [uv](https://docs.astral.sh/uv/)。

```bash
git clone https://github.com/SLKun/WechatDedup.git
cd WechatDedup
uv sync
```

## 使用

> **注意**：操作前请先关闭微信。工具会检测微信进程（`WeChat.exe`、`Weixin.exe`、`WeChatAppEx.exe`），运行时将阻止所有文件操作。

```bash
# 传入 WeChat Files 目录路径启动（路径可在微信「设置 → 文件管理」中查看）
uv run wechat-dedup "C:\Users\<用户名>\Documents\WeChat Files"
```

启动后：

1. TUI 展示已发现的所有微信账号清单
2. 按 `Enter` 进入某个账号，触发按需扫描
3. 扫描完成后自动进入该账号的重复组列表
4. 使用快捷键执行纳管、清理或回溯操作

工具会在 WeChat Files 根目录下创建 `.wechat-dedup.db` 数据库文件，用于保存当前文件清单和操作历史，请勿手动删除。

## 使用说明

### 导航层级

工具采用三层结构浏览当前状态，按 `Enter` / `→` 进入下一层，`Esc` / `←` 返回上一层：

```
账号清单 → 重复组列表 → 组成员（文件列表）
```

- **账号清单**：展示所有已发现的微信账号，已扫描账号显示重复组数、占用空间和可省空间
- **重复组列表**：展示当前账号内所有内容相同的附件分组，按 `s` 可切换排序（可省空间/占用空间/成员数）
- **组成员**：展示一个重复组内的所有附件路径及其状态

按 `h` 可切换到操作历史视图，同样支持三层下钻：操作记录 → 重复组 → 文件结果。

### 三种操作

**纳管（`c`）**：针对已通过硬链接共享数据但尚未被工具管理的文件组。确认其当前关系或将其合并到来源文件，建立操作记录。

**清理（`d`）**：将独立的重复文件替换为与来源文件共享物理数据的硬链接，释放磁盘空间。支持三级作用域：

- 在账号行按 `d`：清理该账号全部可处理重复组
- 在重复组行按 `d`：清理当前组
- 在文件行按 `d`：仅清理当前文件

**回溯（`u`）**：在操作历史中，将已清理的链接文件恢复为独立文件。支持按单个文件、单组或整次账号级清理操作回溯。

### 来源选择

清理时工具自动选择来源文件（优先级：已纳管来源 > 手动来源 > 自动规则）。按 `m` 可手动指定某个文件作为来源，覆盖自动选择。

### 快捷键一览

| 按键               | 功能                       |
| ------------------ | -------------------------- |
| `Enter` / `→` | 进入下一层级               |
| `Esc` / `←`   | 返回上一层级               |
| `c`              | 纳管当前待纳管物理文件组   |
| `d`              | 清理（账号级/组级/文件级） |
| `u`              | 回溯（操作历史中）         |
| `m`              | 切换手动来源               |
| `s`              | 切换重复组排序方式         |
| `h`              | 查看操作历史               |
| `r`              | 重新扫描当前账号           |
| `q`              | 退出                       |

## 工作原理

```
扫描 → 遍历附件目录 → 按文件大小预筛 → BLAKE3 内容摘要 → 识别重复组
                                                              ↓
操作 ← 确认弹窗（微信进程守卫）← 选择来源文件 ← 按快捷键选择作用域
  ↓
硬链接替换（临时文件 + 原子替换）→ 持久化操作记录 → 刷新界面
```

- 纳管和清理通过"创建临时硬链接 → 成功后原子替换"完成，失败时原路径不变
- 回溯通过"复制当前内容为临时独立文件 → 成功后原子替换"完成
- 跨卷文件静默跳过，只读文件自动处理
